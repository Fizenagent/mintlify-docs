# Apply for a Fizen Card


[Get your card](https://url.fizen.io/downloadgb)

{% stepper %}
{% step %}
### Open [Fizen App ](https://url.fizen.io/downloadgb)-> Crypto Card


{% endstep %}

{% step %}
### Apply Card


{% endstep %}

{% step %}
### Submit your information & complete KYC

If you have already KYCed with Sumsub, enter your email for the fast-track process

If you hold a passport/ID of [unsupported-countries.md](unsupported-countries.md "mention") but are living in a supported country, kindly submit the valid documents of your residency to apply for the card. \
\
See the guideline here [exceptions-for-unsupported-countries.md](exceptions-for-unsupported-countries.md "mention")

#### Important

* If you’ve already completed **QR Pay KYC**, do **not** create a new account.
* Use the same **Fizen wallet set** that passed QR Pay KYC to complete your first Card KYC.\
  &#xNAN;_(Example: If you KYCed on BNB Chain, switch to Solana and use that Solana wallet for the card.)_

#### After Card KYC is approved

* You can bind your card to **any on-chain wallet you own**.
* You can update or manage linked wallets later.

This keeps compliance simple while giving you flexibility on funding.

  
{% endstep %}

{% step %}
### Wait for the approval

It will take some time for the card issuer to get your card ready. We'll notify you via in-app push notifications, or you can log in to the app again to check the status

 
{% endstep %}

{% step %}
### Congrats, your card is ready

Most virtual cards are issued within minutes. You can start using your virtual Adventure Card online or via Apple Pay/Google Pay immediately.

 
{% endstep %}

{% step %}
### Finally, top up and start using Fizen Adventure Card

{% content-ref url="top-up-and-pay.md" %}
[top-up-and-pay.md](top-up-and-pay.md)
{% endcontent-ref %}
{% endstep %}
{% endstepper %}
