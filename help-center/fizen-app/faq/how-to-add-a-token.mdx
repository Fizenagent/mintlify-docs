---
title: "How to Add a Token"
---

<Warning>
  Beware of scams — some contracts impersonate real tokens with the same symbol. Only import contracts that are audited or verified.
</Warning>

<Steps>
  <Step title="Go to wallet assets">On the home screen, tap the wallet area to view your assets.</Step>
  <Step title="Tap the + button">Select **+** to add tokens or NFTs.</Step>
  <Step title="Choose how to add">
    - **From list** — select from Fizen's partnered projects
    - **By contract address** — paste the token's contract address manually
    - **By project code** — enter the project code to search
  </Step>
  <Step title="Confirm">The token appears in your wallet balance.</Step>
</Steps>
